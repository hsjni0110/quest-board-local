# 목표와 할 일 — Obsidian 플러그인 (2.5.0)

무료 Obsidian 로컬 플러그인입니다. 독립적인 대시보드 탭에서 목표 및 할 일을 GUI로 관리합니다. 외부 서버와 계정이 필요하지 않습니다.

## 주요 기능

- `중·장기 목표` / `오늘 할 일` 탭 분리
- 중기·장기 목표 생성·수정·달성/미달성 전환·삭제
- 목표에 속한 하위 할 일과 목표와 무관한 일반 할 일 등록·체크·삭제
- **할 일 행 클릭**: 제목, 시작 날짜(⏳), 종료 날짜(📅), 마크다운 노트 편집
- 노트는 `Management/04_TaskNotes/<할 일 ID>.md`에 저장. 한 줄 작성 후 Enter를 누르면 작성한 마크다운이 미리보기로 전환되며, **원문 편집**으로 전체 마크다운 작성 가능
- 7일 / 30일 / 90일 그래프: **할 일을 완료 처리한 로컬 날짜**의 `✅ YYYY-MM-DD`를 집계. 날짜별 막대 클릭 시 완료 내역 표시
- 날짜가 바뀌었거나 앱이 다시 활성화되면 그래프를 새로 계산
- 한글 중심의 낮은 높이 카드와 좌우 적절한 여백

## 설치

1. 기존 Vault를 백업하고 Obsidian을 종료합니다.
2. Vault 내 `.obsidian/plugins/quest-board-local/` 폴더를 만듭니다.
3. 이 저장소의 **`main.js`, `styles.css`, `manifest.json`** 세 파일을 해당 폴더에 복사합니다.
4. Obsidian을 열어 **설정 → 커뮤니티 플러그인 → 목표·할 일 대시보드**를 활성화합니다.
5. 왼쪽 리본의 대시보드 아이콘을 누르거나 명령 팔레트에서 **목표·할 일 대시보드 열기**를 실행합니다.

기존 버전에서 업데이트 시 세 파일만 교체하세요. `Management` 아래의 노트를 덮어쓰지 마세요.

## 저장 위치

Vault 이름과 무관하게 **Vault 내부의 `Management` 폴더**를 고정 사용합니다.

```text
<내 Vault>/
├── .obsidian/plugins/quest-board-local/
│   ├── main.js
│   ├── styles.css
│   └── manifest.json
└── Management/
    ├── 02_Goals/
    │   ├── Active/          # 미달성 목표
    │   └── Cleared/         # 달성 목표
    ├── 03_Lists/
    │   └── Inbox.md         # 일반 할 일
    └── 04_TaskNotes/        # 상세 마크다운 노트 (자동 생성)
```

플러그인은 파일을 마크다운으로 읽고 씁니다. 목표를 삭제할 때 노트와 작업은 Obsidian 휴지통으로 이동합니다. 개별 할 일 삭제는 해당 할 일 줄을 제거하고, 연결된 상세 노트는 휴지통으로 이동합니다.

## 완료 그래프 집계 기준

- **완료일 = 대시보드에서 완료 체크한 시점의 로컬 날짜**입니다. 작업 시작일·마감일과 관계없습니다.
- 완료 체크: `- [x] 할 일 이름 ✅ 2026-11-09 ^qb-...`
- 다시 미완료로 바꾸면 완료일이 지워지며, 다시 완료하면 그날 날짜로 새롭게 기록됩니다.
- 목표 자체의 달성/미달성 상태 변경은 그래프에 포함되지 않습니다.
- 목표 하위 업무와 일반 할 일을 모두 포함합니다.
- 기존에 완료한 일 중 **완료 날짜(✅)가 없는 항목은 임의 날짜로 추정하지 않습니다**.
- 날짜는 Obsidian을 실행 중인 기기의 로컬 시간대를 사용합니다. 한국 시간으로 사용하려면 기기 시간대를 Asia/Seoul로 설정하세요.
- 완료 노트가 삭제되면 해당 업무의 완료 기록 역시 집계에서 제외됩니다.

## 할 일 상세 노트

1. 대시보드에서 **할 일 행의 빈 공간 또는 제목**을 누릅니다. 체크박스를 누르면 상세가 아닌 완료 토글만 수행합니다.
2. 상세 창에서 제목·시작 날짜·종료 날짜를 수정할 수 있습니다.
3. 아래 노트 영역에서 `## 소제목`, `- 목록`, `**강조**` 등 마크다운을 입력하세요.
4. Enter로 다음 줄을 만들면 앞 줄의 마크다운이 렌더링됩니다. 클릭하면 다시 편집할 수 있습니다.
5. 여러 줄을 한 번에 수정하거나 표·코드블록 등 복잡한 형식을 쓰려면 **원문 편집** 모드 또는 **노트에서 열기**를 사용하세요.
6. **저장**을 누르면 할 일 메타데이터는 원본 목표 노트 또는 Inbox에, 본문은 별도 TaskNotes 노트에 저장됩니다.

> 줄별 마크다운 편집은 가벼운 노션식 미리보기입니다. Obsidian 전체의 Live Preview와 완전히 동일한 블록 에디터는 아닙니다. 복잡한 서식은 Obsidian 편집기에서 여는 것이 가장 정확합니다.

## GitHub에 직접 게시하기

ZIP을 풀고 이 폴더를 원하는 위치에 놓은 뒤 다음을 실행할 수 있습니다. GitHub에서 **새 공개 저장소를 먼저 생성**하세요.

```bash
git init
git add .
git commit -m "Initial release of Obsidian Quest Board v2.5"
git branch -M main
git remote add origin https://github.com/hsjni0110/<새-저장소-이름>.git
git push -u origin main
```

공개 전에 테스트 파일이나 개인 Vault 내용이 섞이지 않았는지 확인하세요. 제공 패키지에는 사용자의 실제 목표·할 일 노트가 없습니다. 공개 라이선스는 본인이 선택해 추가하세요.

## 테스트

Node.js가 있다면 `npm test` 또는 `node tests/smoke-test.cjs`를 실행하세요. 외부 패키지는 필요하지 않습니다. 날짜 이월, 할 일 행 클릭, 상세 노트 저장, 기존 목표/일반 할 일 흐름을 가상 Obsidian API로 검사합니다.
